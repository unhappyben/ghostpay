RELAYER API

serve.mjs, same origin as the app. mainnet only (chainId 1). all bodies are JSON; all errors are {"error":"…"}, never stack traces.

CONVENTIONS

  • Write endpoints (/announce, /sweep, /pp-withdraw) are rate limited per IP and may require Authorization: Bearer <token>: see RELAYER.
  • Broadcasts are delayed by a random jitter (announce 2-15s, sweeps and withdrawals 5-45s). A 200 means the transaction was accepted by the broadcast endpoint, not that it is mined. Poll GET /status/:hash.
  • Successful broadcast responses share a shape: {"hash":"0x…","runner":"0x…","delayedSec":12}.
  • Without a configured runner the write endpoints return 503. Static serving is unaffected.

POST /announce

Announces a stealth payment on the ERC-5564 announcer (0x55649E01B5Df198D18D95b5cc5051630cfD45564, scheme 1) from a runner wallet. Calls announce(1, stealth, ephPub, metadata).

FIELDTYPERULES
stealthaddressRequired. The one-time stealth address being announced.
ephPub0x-hexRequired. 33-byte compressed secp256k1 point: 0x + 66 hex chars.
viewTagnumberRequired when metadata is absent. Integer 0-255. The metadata then defaults to the 1-byte view tag.
metadata0x-hexOptional. 1-1024 bytes, used verbatim (packed view tag + encrypted memo). When present, viewTag is ignored.
curl -X POST http://localhost:8791/announce \
  -H 'content-type: application/json' \
  -d '{"stealth":"0x…","ephPub":"0x02…","viewTag":137}'
# → {"hash":"0x…","runner":"0x…","delayedSec":7}

POST /sweep

Relays a signed sweep artifact. The runner pays the gas; the stealth EOA never needs funding. The kind field selects one of four artifact shapes.

kind: eip3009

Executes USDC transferWithAuthorization (gasless for the holder).

FIELDRULES
kind"eip3009"
tokenToken contract address (the call target).
from, toAddresses. from is the stealth address, to the destination.
value, validAfter, validBeforeuint256 values, as accepted by the token contract.
noncebytes32 EIP-3009 nonce.
signature65-byte 0x-hex signature, split into v/r/s by the relayer.

kind: eip7702-sweep (legacy v1)

Type-4 transaction: the stealth EOA delegates to the v1 sweeper and the relayer-chosen calldata runs as the EOA. Trust assumption: the relayer picks the calldata, so use intent sweeps where available.

FIELDRULES
kind"eip7702-sweep"
stealthAddressThe stealth EOA. Transaction target.
authorizationEIP-7702 authorization: {chainId, address, nonce, yParity, r, s}. address is the sweeper contract; nonce must equal the stealth EOA's current nonce or the request 400s as stale.
dataCalldata executed as the EOA (e.g. a sweeper call). Privacy Pools deposits below the 0.01 ETH pool minimum are rejected at preflight.
sweeper, precommitmentInformational, echoed back to the operator in logs.

kind: eip7702-intent

The default flow. Type-4 transaction executing executeSweep(intent, sig) on the stealth EOA delegated to SweeperV2. Requires SWEEPER_V2 configured on the relayer (else 503). Every parameter of the sweep comes from the signed intent: the relayer can deliver or censor, never redirect.

FIELDRULES
kind"eip7702-intent"
stealthAddressThe stealth EOA. Also the EIP-712 verifyingContract and the transaction target.
authorizationEIP-7702 authorization delegating the EOA to SweeperV2: {chainId, address, nonce, yParity, r, s}.
intent.actionuint8: 0 = ETH to destination · 1 = Privacy Pools ETH deposit · 2 = PP token deposit · 3 = token to destination.
intent.tokenaddress. Actions 2/3 only; ignored otherwise.
intent.destinationaddress. Actions 0/3 only; ignored otherwise.
intent.precommitmentuint256. Actions 1/2 only: poseidon2(nullifier, secret) for the Privacy Pools deposit.
intent.feeBpsuint256. Relayer fee in basis points, paid to tx.origin. Must be >= the relayer floor (MIN_FEE_BPS, default 30) and <= the onchain cap (1000).
intent.deadlineuint256 unix seconds. Expired intents are rejected with a 400: sign a fresh sweep in the app.
signature65-byte 0x-hex EIP-712 signature by the stealth key (see below).

The signed payload, verified at preflight before any gas is spent:

domain:  { name: "GhostpaySweeper", version: "1", chainId: 1,
           verifyingContract: <stealthAddress> }
struct:  SweepIntent(uint8 action,address token,address destination,
                     uint256 precommitment,uint256 feeBps,uint256 deadline)

Preflight rejects: a signature that does not recover to stealthAddress, an expired deadline, a fee below the floor, and any broadcast the runner cannot afford. Failed gas estimation is a hard error: a malformed intent never burns runner gas onchain.

curl -X POST http://localhost:8791/sweep \
  -H 'content-type: application/json' \
  -d '{"kind":"eip7702-intent","stealthAddress":"0x…",
       "authorization":{"chainId":1,"address":"0xCC29c7723116155ccF20C7c0b8924F4747331903","nonce":0,"yParity":0,"r":"0x…","s":"0x…"},
       "intent":{"action":1,"token":"0x0000000000000000000000000000000000000000","destination":"0x0000000000000000000000000000000000000000","precommitment":"…","feeBps":"30","deadline":"…"},
       "signature":"0x…"}'

kind: eip7702-intent-batch

One type-4 transaction to BatchRelayer sweeping up to 20 stealth EOAs: cheaper per sweep, one gas payment. Requires BATCH_RELAYER configured (else 503; BatchRelayer is not deployed yet). Each entry of sweeps is a full eip7702-intent artifact minus the kind field and is verified independently.

FIELDRULES
kind"eip7702-intent-batch"
sweepsArray of 1-20 {stealthAddress, intent, signature, authorization} entries.

Semantics: the authorization list delegates every EOA to SweeperV2, then one relay(targets, datas) call runs each executeSweep, all-or-nothing. Fees still land on tx.origin, not the BatchRelayer contract. Caveat: a batch shares one transaction, so the swept addresses are linked onchain.

POST /pp-withdraw

Privacy Pools withdrawal relay. Requires PP_RELAY=1 (else 503). Same payload shape the app sends fastrelay.xyz, so client code is interchangeable.

FIELDRULES
chainIdMust be 1.
scopeDecimal string. Must equal the mainnet ETH Privacy Pool scope; other pools are refused.
withdrawal.processooorMust be the Privacy Pools entrypoint 0x6818809EefCe719E480a7526D76bD3e561526b46.
withdrawal.data0x-hex abi.encode(address recipient, address feeRecipient, uint256 relayFeeBPS).
proofsnarkjs groth16/bn128 JSON: {protocol:"groth16", curve:"bn128", pi_a, pi_b, pi_c}, all decimal strings.
publicSignalsExactly 8 decimal strings, each below the snark scalar field.
feeCommitmentOptional, ignored by this relay (present for fastrelay.xyz compatibility).

Validation, in order: chainId and scope pin the deployment; the decoded feeRecipient must be one of this server's runners (re-quote against GET /health and re-prove otherwise); relayFeeBPS must not exceed PP_FEE_BPS (default 25); the context public signal (publicSignals[7]) must match the keccak of the withdrawal struct + scope reduced mod the snark field, which binds the proof to exactly these fee terms; withdrawnValue must be nonzero. Gas estimation then simulates the full withdrawal including proof verification, so a bad proof fails here with a clean error instead of reverting onchain.

curl -X POST http://localhost:8791/pp-withdraw \
  -H 'content-type: application/json' \
  -d '{"chainId":1,"scope":"4916…","withdrawal":{"processooor":"0x6818…","data":"0x…"},
       "proof":{"protocol":"groth16","curve":"bn128","pi_a":["…","…"],"pi_b":[["…","…"],["…","…"]],"pi_c":["…","…"]},
       "publicSignals":["…","…","…","…","…","…","…","…"]}'
# → {"hash":"0x…","txHash":"0x…","runner":"0x…","delayedSec":31,
#    "recipient":"0x…","feeBps":25,"feeWei":"…"}

GET /health

Relayer status. Never keys, never the API token.

FIELDMEANING
oktrue.
chainId1.
runnersRunner addresses (public onchain anyway).
runnerCountPool size.
runnerBalancesMap of runner address to ETH balance (number), 30s cache. Per-runner best-effort: an RPC failure yields null for that runner, never a failed health check.
sweeperV2Configured SweeperV2 address, or null. Non-null means the relayer accepts eip7702-intent.
batchRelayerConfigured BatchRelayer address, or null.
minFeeBpsFee floor for intent sweeps.
ppRelaytrue when POST /pp-withdraw is enabled.
ppFeeBpsWithdrawal relay fee in bps. Present only when ppRelay is true.
feeOwnerAuto-forward owner address, or null when the forwarder is disabled.
rateLimitedAlways true: the write endpoints are rate limited per IP.
authRequiredPresent and true only when GHOSTPAY_API_TOKEN is set.
tortrue when JSON-RPC routes over TOR_PROXY.
endpointsHostnames of the read RPC rotation.

GET /fee

The relayer fee floor for intent sweeps.

curl http://localhost:8791/fee
# → {"minFeeBps":30}

GET /price

ETH + USDC USD prices, proxied from CoinGecko with a 60s cache so the price fetch stays out of the user's browser. 503 when the feed is unavailable.

curl http://localhost:8791/price
# → {"ethereum":{"usd":3123.45},"usd-coin":{"usd":1.0}}

GET /status/:hash

Transaction receipt status. Broadcasts go to Flashbots Protect's private mempool, so pending here means "no receipt yet": explorers will show nothing until mined.

curl http://localhost:8791/status/0x…64hex…
# → {"status":"pending"}
# → {"status":"confirmed","blockNumber":23501234}
# → {"status":"failed"}

A malformed hash (not 0x + 64 hex) gets a 400.
